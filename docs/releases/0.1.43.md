## Español

- **Widget para la pantalla de inicio.** Pequeño, es un botón **+** que abre Fulla directamente en Anotar. Más ancho, muestra además cuánto te queda del periodo, cuánto puedes gastar al día y lo gastado. Toca las cifras para abrir el Resumen.
- **Importes ocultos si quieres.** En Ajustes, «Ocultar importes en el widget». Con la app bloqueada, el widget nunca muestra importes.
- **Atajos en el icono.** Mantén pulsado el icono de Fulla para «Añadir gasto» o «Añadir ingreso».
- **Actualizar la base de datos sin el editor SQL.** Cuando Ajustes avise de una actualización, pega un token de Supabase y Fulla la aplica sola. El token no se guarda; bórralo después. Copiar el SQL sigue disponible.

## English

- **Home-screen widget.** Small, it is a **+** button that opens Fulla straight on Add. Wider, it also shows what is left of the period, how much you can spend per day and what was spent. Tap the figures to open the overview.
- **Amounts hidden if you like.** In Settings, "Hide amounts in the widget". While the app is locked, the widget never shows amounts.
- **Shortcuts on the icon.** Long-press Fulla's icon for "Add an expense" or "Add an income".
- **Update the database without the SQL editor.** When Settings says an update is due, paste a Supabase token and Fulla applies it itself. The token is not kept; delete it afterwards. Copying the SQL is still there.
