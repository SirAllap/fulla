## Español

- **Eliminar una meta.** Dentro de una meta, «Eliminar meta»: desaparece para todo el hogar. Archivarla sigue sirviendo para apartarla sin perderla. Necesita actualizar la base de datos del hogar (Ajustes › Sincronización).

## English

- **Delete a goal.** Inside a goal, "Delete goal": it disappears for the whole household. Archiving still sets one aside without losing it. Needs the household's database updated (Settings › Sync).
