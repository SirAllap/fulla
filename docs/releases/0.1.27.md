A fixed cost can be deleted.

- **Fixed costs have a Delete button.** Open the fixed cost and tap **Delete**. It stops writing and leaves the list. What it already wrote stays in History, unless you choose **Delete it and its N written entries**, which removes those too (handy after trying a fixed cost out).
- Deleting a fixed cost does not touch anything else: other fixed costs, and the rest of your entries, stay as they are.
- A fixed cost that is only **paused** (the Active switch) stays in the list, as before.

**Database update (shared households that use Supabase):** this version adds one small migration, `0021_recurring_archived.sql`, so a deleted fixed cost stays deleted for everyone. Settings › Update the database copies it. Until it is applied, Delete on a shared household pauses the fixed cost instead of removing it from the list. Households that live only on your phone need nothing.
