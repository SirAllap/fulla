Starting balances with a date.

- An account's starting balance now has a day: **Balance at the start of** a date, today by default. Movements from that day on are added or subtracted; earlier ones are already in it, so adding past expenses no longer counts them twice.
- Balances set before this version keep working as before.

**Using your own Supabase project?** Run the new `setup.sql` from this release in your project's SQL Editor, as before.

On 0.1.10? Fulla offers this at the top of Settings, or tap **Settings › About › Check now**, then **Update now**.
