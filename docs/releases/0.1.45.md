## Español

- **Volver a entrar con «Ya tengo un proyecto» funciona.** Al pulsar «Conectar», la app comprobaba la base de datos antes de iniciar sesión y decía, sin razón, que el proyecto no tenía la base de datos de Fulla. Ahora comprueba la dirección y la clave primero, y la base de datos justo después de iniciar sesión.
- **Mensajes claros.** Si la clave no es la de ese proyecto, o está cortada, lo dice. Si el proyecto no responde en ese momento, también.
- **Basta con el ID del proyecto.** En «URL del proyecto» puedes pegar solo el ID de 20 letras que enseña Supabase.

## English

- **Getting back in with "I already have a project" works.** Tapping "Connect" checked the database before signing in and wrongly said the project had no Fulla database. Now it checks the address and the key first, and the database right after signing in.
- **Clear messages.** If the key is not that project's, or is cut short, it says so. If the project is not answering at that moment, too.
- **The project's ID is enough.** In "Project URL" you can paste just the 20-letter ID Supabase shows.
