Fulla tells you when your database needs an update.

- **Using your own Supabase project?** When a release changes the database, Fulla now says so at the top of Settings. Tap **Update database**: it copies the update and opens your project's SQL Editor. Paste and press **Run**.
- This release adds that check, so run the new `setup.sql` from this release one last time in your SQL Editor. From now on Fulla will ask you when it's needed.

On 0.1.12? Fulla offers this at the top of Settings, or tap **Settings › About › Check now**, then **Update now**.
